# Pliego v0.3.1

Pliego 0.3.1 is the Linux headless compatibility patch for the public API 2
base-engine release.

## What changed

- Linux pins Mesa software rendering at process startup, before Servo or surfman
  can initialize in the supervisor process. This prevents unavailable DRI/Zink
  probes from leaking native warnings into API 2's reserved stderr channel.
- The packaged Linux runtime is exercised on Ubuntu 24.04 with caller graphics
  overrides removed. A successful render must still return exit `0`, one canonical
  result on stdout, and empty stderr.
- The API 2 schema, profile-null tuple, artifacts, render identity, and API 1
  compatibility boundary are unchanged from v0.3.0.

## Why this is a patch release

The v0.3.0 Linux archive rendered successfully on the Ubuntu 24.04 host used by
the PHP package gate, but Mesa also wrote device-probe diagnostics to stderr. The
PHP client correctly rejected that unsupported success tuple. v0.3.1 fixes the
native process boundary instead of weakening the public contract or replacing an
already-published immutable asset.

## Publication gate

The patch is complete only when the exact native v0.3.1 tag has successful
packaged Linux, Windows, macOS x86-64, macOS arm64, and Ubuntu 24.04 headless
evidence; GitHub marks v0.3.1 latest; both Composer packages resolve v0.3.1 from
Packagist at their exact tags; and a fresh public-only consumer completes install,
doctor, render, storage, retrieval, and typed-failure checks.
