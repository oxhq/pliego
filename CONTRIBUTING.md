# Contributing to Pliego

Pliego follows Servo's contribution workflow for inherited code:

- [Contributing to Servo](https://book.servo.org/contributing/getting-started)

## Licensing

Contributions use the license that applies to each changed file: MPL-2.0 for new Pliego-owned files
outside `sdk/**`, MIT for independently authored client SDK files, and the existing license for
inherited or third-party files. Preserve all existing license and copyright notices.

Each commit authored for and submitted directly to Pliego must include a `Signed-off-by` line under the
[Developer Certificate of Origin 1.1](https://developercertificate.org/). No contributor license
agreement or copyright assignment is required. Imported upstream history is exempt. See
[ADR 0012](docs/pliego/adr/0012-license-and-notice-strategy.md) for the full boundary.
