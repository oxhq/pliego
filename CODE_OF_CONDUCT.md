# Code of Conduct

Pliego follows the [Rust Code of Conduct](https://www.rust-lang.org/policies/code-of-conduct).
It applies to the `oxhq/pliego` repository and any project space represented as an
official Pliego venue.

Use GitHub's reporting and blocking tools for immediate safety concerns. Report
conduct concerns confidentially through the repository's
[private reporting form](https://github.com/oxhq/pliego/security/advisories/new),
prefixing the report title with `Conduct:`. Do not place private or identifying
information in a public issue.
